# TS-03 Боковое меню — тест-кейсы

**Файл с тестами:** `tests/test_side_menu.py`
**Parent suite:** `side_menu`

> **Примечание:** Тестовый клиент «Авто_тест» создаётся автоматически перед первым тестом через фикстуру `auto_client` (тариф ПРО пробный + источники Fake и Fake Geo). После завершения всех тестов сьюта клиент удаляется. Ручной выбор клиента в шагах не требуется.

---

## История изменений

### 2026-03-24 — Добавлены TC-0337s–TC-0344s: навигация со страницы Клиенты

Добавлены 8 тест-кейсов в `TestTS03SideMenu` (субадмин, широкое меню). Тесты проверяют кнопки быстрой навигации в строке клиента на странице `/clients`:
- кнопка «Смотреть отзывы клиента» → `/1?feedbacks_tab=pending&client_id=...`
- кнопка «Смотреть товары клиента» → `/products/1?client_id=...`
- кнопка «Карты» → `/pois/1?client_id=...`
- кнопка «Смотреть бренды клиента» → `/brands/{client_id}`
- кнопка «Смотреть группы шаблонных ответов клиента» → `/settings/template-answers?client_id=...`
- кнопка «Смотреть пользователей клиента» → `/settings-company/users?client_id=...`
- кнопка «Настройки компании клиента» → `/settings-company/settings?client_id=...`
- кнопка «Финансы» → `/settings-company/billing?client_id=...`

Все тесты используют фикстуру `auto_client` (клиент «Авто_тест»). Добавлены методы в `ClientsPage`, локаторы в `ClientsPageLocators`, константы в `Endpoints`.

---

### 2026-03-19 — Удаление шага ввода SMS-кода из авторизации

Из всех фикстур авторизации (`conftest.py`) удалён шаг подтверждения входа через SMS-код: после нажатия кнопки «Войти» редирект на дашборд происходит напрямую. Обновлены методы `authorization_user` и `authorization_user_wildcard` в `pages/authorization_page.py`.

Также внесены фиксы стабильности:
- `pages/operator_page.py` — для всех кнопок профиль-дропдауна оператора добавлен `force=True` и пауза для стабилизации dropdown-а
- `pages/side_menu_page.py` и `pages/operator_page.py` — улучшен fallback в `wait_for_new_tab_and_get_url`: ожидание URL с «instructions» вместо любого изменения URL
- `conftest.py` — `wait_for_load_state("networkidle")` на странице биллинга обёрнут в try/except

**Известные проблемы (баг приложения, не тесты):**
- TC-0314s, TC-0314m, TC-03004o — кнопка «Смотреть инструкции» не открывает новую вкладку и не навигирует. Тесты фиксируют этот баг.

**Результат:** 72/76 тестов проходят.
