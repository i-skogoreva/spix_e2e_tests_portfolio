# TC-0001: Successful user authorization [subadmin / manager / operator]

**Severity:** CRITICAL

**Параметризация:** тест выполняется для трёх ролей — subadmin, manager, operator (каждая со своими учётными данными).

**Шаги:**
1. Открыть страницу авторизации (`/signin/`)
2. Ввести валидный номер телефона для соответствующей роли в поле "Телефон"
3. Ввести валидный пароль для соответствующей роли в поле "Пароль"
4. Нажать кнопку "Войти в систему"
5. Дождаться появления формы ввода SMS-кода
6. Ввести 6-значный SMS-код (123456)
7. Нажать кнопку "Войти"

**Проверки:**
1. Происходит редирект на страницу фидбэка (`/1?feedbacks_tab=pending`)

# TC-0115: Успешная авторизация менеджера

**Severity:** CRITICAL

**Шаги:**
1. Открыть страницу авторизации и войти под субадмином (телефон + пароль + SMS-код)
2. Перейти на страницу Клиенты (/clients)
3. Нажать кнопку "+" для создания нового клиента
4. Заполнить название и email клиента, нажать "Добавить"
5. На странице настроек клиента перейти на вкладку "Пользователи"
6. Заполнить форму создания менеджера (имя, email, телефон, пароль), выбрать роль "Менеджер", нажать "Сохранить"
7. Перейти на страницу авторизации (/signin/)
8. Авторизоваться под созданным менеджером (телефон + пароль + SMS-код)

**Проверки:**
1. Менеджер успешно авторизован и перенаправлен на страницу отзывов (URL содержит feedbacks_tab=pending)

# TC-0116m/0117m/0118m: SMS-страница на языке менеджера [Русский / English / Indonesia]

**Severity:** NORMAL

**Параметризация:** тест выполняется для трёх языков — Русский (TC-0116m), English (TC-0117m), Indonesia (TC-0118m).

**Шаги:**
1. Авторизоваться под субадмином, создать клиента и перейти к форме добавления пользователя (фикстура `client_page`)
2. Заполнить форму создания менеджера (имя, email, телефон, пароль), выбрать роль "Менеджер", нажать "Сохранить"
3. Кликнуть по созданному менеджеру в списке пользователей → переход на страницу редактирования
4. Сменить язык в профиле менеджера на выбранный язык, нажать "Сохранить"
5. Очистить cookies, перейти на страницу авторизации (/signin/)
6. Ввести учётные данные менеджера (телефон + пароль), нажать "Войти в систему"

**Проверки:**
1. Тексты SMS-страницы соответствуют выбранному языку: заголовок, описание, лейбл поля кода
