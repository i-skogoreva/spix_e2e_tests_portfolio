# TC-0401s: Субадмин подключает пробный бесплатный тариф ПРО

**Severity:** CRITICAL

## Шаги

1. Субадмин авторизован. Создан клиент с Демо-тарифом (фикстура `demo_client`)
2. Открыть страницу биллинга `/settings-company/billing?client_id={id}` для demo-клиента
3. Нажать кнопку "Улучшить" (`.billing-package__btn`)
4. На странице выбора тарифа прокрутить к разделу "Бесплатные тарифы"
5. Нажать "Подключить" на карточке ПРО (пробный, 7 дней)
6. Подтвердить выбор — кнопка "Уверен"
7. Закрыть окно успеха — кнопка "Отлично"

## Проверки

1. Текст текущего тарифа (`.billing-package__col-title`) содержит "ПРО"

# TC-0403s: Добавление токенов

**Severity:** CRITICAL

## Шаги

1. Субадмин авторизован. У клиента подключён тариф БИЗНЕС (после TC-0402s)
2. Открыть страницу биллинга `/settings-company/billing?client_id={id}` для demo-клиента
3. Запомнить текущий остаток токенов (`.billing-balance__consumption`, формат "X  ИЗ  Y")
4. Нажать кнопку "Добавить токены на период" (`.billing-balance__btn-add-tokens`)
5. В модальном окне ввести количество токенов (100) и комментарий "Токены для инсайтов"
6. Нажать "Сохранить"
7. Дождаться закрытия модалки и обновления баланса на бэкенде (до 5 попыток с навигацией)

## Проверки

1. Остаток пакета увеличился на указанное количество токенов (было + 100 = стало)

# TC-0406s: Добавление платёжной информации: расчётный счёт

**Severity:** CRITICAL

## Шаги

1. Субадмин авторизован. Открыта страница биллинга для demo-клиента
2. Нажать "Добавить" в секции "Платёжная информация" (`.payment-info__card-footer button`)
3. Выбрать способ оплаты "Рас. счет" (`.payment-method-btn__title`)
4. Ввести название организации (например, "Сбербанк") в поле "Наименование организации" (`input.name-company`)
5. Дождаться появления подсказок автодополнения (`.form-field__suggestion`) и выбрать первую
6. Поля ИНН, ОГРН, Юридический адрес заполняются автоматически
7. Нажать "Сохранить"

## Проверки

1. В секции "Платёжная информация" (`.payment-info`) отображается текст "Расчетный счет"
